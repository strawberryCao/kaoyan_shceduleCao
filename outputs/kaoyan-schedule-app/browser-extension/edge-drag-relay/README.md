# 考研资料磁吸接力 Edge 扩展

这是一个 Manifest V3 本地扩展。它只响应考研学习中心写入的
`application/x-kaoyan-material-v1` 拖拽协议。

## 安装

1. 在 Edge 打开 `edge://extensions`。
2. 打开“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择本目录 `browser-extension/edge-drag-relay`。
5. 在扩展详情中确认“网站访问”允许在需要接力的网页上运行。

## 使用

在考研学习中心的速记资料列表中按住某项，拖到另一个 Edge
窗口中的普通网页并松手。目标页会显示磁吸动画，随后生成可移动的资料预览。
磁吸不会在发起拖拽的学习中心窗口内触发。使用期间请保持本地笔记服务运行，
以便目标窗口根据临时传输 ID 读取资料。

浏览器设置页、扩展商店、内置 PDF 阅读器等受保护页面不允许内容脚本注入，
因此不能作为接收页。

## 隐私

- 页面截图只在拖拽动画期间留在内存中，不上传、不保存。
- `DataTransfer` 只携带随机传输 ID 和协议元数据，不携带本地绝对路径。
- 资料登记两分钟后自动失效。
- 普通文件、文本和网页自身的拖放不会被扩展拦截。
