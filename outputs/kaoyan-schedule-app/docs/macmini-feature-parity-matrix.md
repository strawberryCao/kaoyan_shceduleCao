## 2. 状态定义

- **保留**：现有产品行为必须原样或等价迁移。
- **增强**：保留能力并针对 Mac 服务端或跨设备体验补强。
- **重构**：用户能力不变，但底层实现必须替换。
- **排除**：经用户确认不迁移。

## 4. 数据守恒清单

迁移工具必须对每个来源和最终 Mac 库生成机器可读及人可读报告，至少比较：

- 实体总数、按类型/科目/Facet 数量、稳定 ID、创建和修改时间。
- 正文、标题、备注、来源、批次、题序、人工编辑字段和未知扩展字段。
- 附件数量、顺序、显示名、MIME、字节数、SHA-256 和可读性。
- 画布节点、墨迹、关系、锚点、图片引用和草稿状态。
- 卡片内容、复习状态、评分历史、错误次数和下次计划。
- 删除墓碑、恢复记录、冲突决定、同步回执和 AI 任务状态。
- Windows 绝对路径、孤儿附件、重复 sidecar、冲突副本和损坏 JSON 的隔离清单。

验收不以“页面看起来有数据”为准。记录字段数、附件哈希或人工决定任一不守恒，都不得切换权威源。

## 5. 跨设备核心场景

1. Windows 离线用 Electron 连续保存文字、图片、PDF 和追加资料；重启后仍完整，Mac 恢复后只同步一次并收到 AI 结果。
2. 手机经 Tailscale 拍摄 1/2/4/8/12 题页面；断网、切后台、锁屏和 Safari 被杀后恢复，Mac 确认后本地密文被删除。
3. iPad 编辑画布和人工分类，Windows 同时修改独立字段；Mac 自动合并且不覆盖人工决定。
4. 同一操作在超时后重复提交；记录、附件和 AI 费用均不重复。
5. Tailscale 路径不可用时，授权用户可经 Cloudflare 备用入口访问同一最新数据；恢复后无需合并两个云端权威库。
6. Cloudflare 中断时，Tailscale 和 Windows 本地副本继续工作。
7. Mac 服务重启、进程崩溃或数据库恢复后，已确认写入不丢失，未完成任务可观察且不会自动重复付费。
8. Mac 冷启动时验证 FileVault 运维提示；磁盘解锁、系统启动后无需进入桌面即可恢复核心服务。

## 6. 视觉、交互与流畅度验收

- 390px、768px、1280px、1440px 四档无非业务横向滚动、遮挡和裁切；关键触控目标至少 44×44px。
- Electron 速记小窗冷启动、聚焦、粘贴、保存和关闭保持轻量；后台同步与 AI 不抢占输入响应。
- 保存反馈必须区分“Windows 本地已保存 / 移动端已加密排队 / Mac 已接收 / AI 已完成”。
- 页面切换保留筛选、草稿、选择和滚动；长列表不一次挂载全部重型预览。
- 图片、PDF、Word、HTML 不可用时给出对应降级动作，不能只显示空白或永久 loading。
- 动画支持 `prefers-reduced-motion`；AI 只以任务状态和可选建议出现，不改变产品为聊天式界面。
- 后续 UI 阶段必须在真实 Windows、Mac、iPhone Safari 和 iPad Safari 上走查，构建和模拟视口不能替代实机验收。

## 7. 后续阶段的量化门槛

具体毫秒和容量指标先在第二阶段采集现状基线，再冻结阈值，避免凭空承诺。最终至少量化：

- Mac 服务冷/热启动、页面首屏、数据库查询 P50/P95、事件推送延迟。
- Windows 小窗打开、保存到本地、同步确认和离线积压恢复时间。
- 手机/iPad 首屏、加密入队、上传确认、大附件和多题批处理耗时。
- Cloudflare 与 Tailscale 两条路径的端到端差异。
- 空闲/峰值 CPU、内存、磁盘增长、数据库/附件备份和恢复时间。
- 连续 30 批真实图片的丢失、重复、卡死、AI 重复调用和命名/分类校验结果。
