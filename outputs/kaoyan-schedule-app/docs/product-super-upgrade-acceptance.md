# 产品超级升级验收合同

本文档约束 `codex/product-super-upgrade` 分支。升级可以重做信息架构和视觉层，但不能破坏已经稳定的数据、安全和跨端行为。

## 产品主线

- 画布是高频核心功能，必须保留桌面端一级入口和移动端底栏入口。
- 一级主线为：今天、画布、学习计划、复习与资料。
- 捕获是全局动作，在桌面侧栏和移动端底栏都能一步触达。
- 任务动态、桌面控制台和 AI 自动化属于工作台能力，不得挤占学习主线。
- 画布、笔记、题目、复习卡和计划任务最终必须能够互相建立稳定链接。

## 画布体验底线

- 不自动删除历史画布或空白画布；任何整理都必须可预览、可撤销、可从回收站恢复。
- 画布打开、缩放、书写、拖图和保存时不能因为 AI 分析而阻塞。
- 用户手动标题优先；AI 只能建议标题，不能静默覆盖。
- 画布列表需要最近使用、收藏、科目、关联资料和可恢复草稿视图。
- Windows、触屏和 Apple Pencil 提示必须按实际输入设备显示。

## 数据与同步底线

- `attachments`、`facets`、`sourceType`、`sourceBatchId`、`sourceSplitIndex`、`sourceImageHash`、`userEditedFields`、`studyNotes`、`items` 和 `cards` 全字段保真。
- 本地与云端冲突必须字段级合并，不能整条记录覆盖。
- 人工标题、备注、分类、错因、标签和删除决定优先于后台 AI。
- 移动捕获先写本地可靠队列，再反馈成功；不得把“本地已入队”表述成“云端已完成”。
- noteUid、附件哈希和操作 ID 必须幂等；弱网、切后台、锁屏和重启后可恢复。
- 远端数据禁止写入 Windows 绝对路径；自动同步继续默认暂停。

## AI 与命名底线

- 带附件速记保存后自动命名速记标题和全部资料。
- 追加资料后，结合正文以及全部新旧附件重新理解和命名整组资料，而不是只命名新增附件。
- 创建时用户手填标题必须保留。
- 手动“AI 命名资料／AI 重命名”继续作为重试和重新生成入口。
- 纯文本无附件速记不触发资料命名。
- 启动时不得扫描或批量重命名历史资料，避免意外 AI 调用风暴。
- 公网和局域网必须共享标题、科目、知识路径和人工字段保护规则。

## UI 与人机交互验收

- 390px、768px、1280px 和 1440px 四档视口不得出现非业务需要的横向滚动或控件裁切。
- 触控目标不小于 44px；键盘焦点可见；图标按钮有可读名称。
- 保存、启动小窗、同步、AI 分析、失败和重试必须有明确状态反馈。
- 首次加载可以使用骨架或局部加载态，已呈现页面不能被无期限全屏旋转动画替代。
- 动画以 120–220ms 为主，并遵循 `prefers-reduced-motion`。
- 页面切换保留筛选、编辑草稿和滚动上下文；捕获不能因路由切换丢失输入。
- 长列表使用虚拟化或分段渲染，图片懒加载；输入、书写和拖拽保持即时响应。
- 空状态必须说明发生了什么，并提供一个最主要的下一步动作。

## 发布与验证约束

- 不重置、覆盖或顺带格式化用户已有的无关工作区改动。
- 不修改无关 Windows 启动脚本的编码或换行。
- 未经用户明确许可，不部署 Cloudflare、不写生产数据仓库、不自动启用同步。
- 每个阶段至少通过 TypeScript、正式构建、离线测试和 `git diff --check`。
- 捕获或同步相关改动还必须覆盖本地与公网双路径、Safari 恢复、附件顺序、重复提交和人工字段保护测试。
- UI 阶段必须用真实桌面和移动视口完成浏览器走查，不能只以构建成功作为验收。
